Options that change behaviour

mouse = ''mouse fully off
clipboard = unnamedplusyanks and deletes hit the macOS clipboard
number + relativenumbergutter shows the jump distance
ignorecase + smartcaselowercase search is loose, capital is exact
scrolloff = 1616 lines of context always visible
undofileundo survives quitting
expandtab, shiftwidth = 22 spaces, never tabs
