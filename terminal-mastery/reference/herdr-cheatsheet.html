Herdr

Read from herdr --default-config, herdr --skill and your ~/.config/herdr/config.toml. Prefix is Right ⌘ - press and release, then the next key alone. macOS remaps that key to F12 so a terminal can carry it, which is why it works the same over ssh.

Your four action overrides

ActionDefaultYours
split_horizontalRight ⌘ -Right ⌘ "
split_verticalRight ⌘ vRight ⌘ %

The fifth override is the one-key Right ⌘ prefix. Everything else in your config restates a Herdr default.

Agent states

workingrunning - leave it
blockedneeds you - approval or question
donefinished while unseen
idleready, and you have already looked
unknownpresent but unclassified. Not proof of completion.

Focusing the tab flips done to idle. A CLI read does not. Scan for done and blocked; ignore the rest.

CLI - look around

herdr status
herdr workspace list
herdr tab list --workspace w1
herdr pane list --workspace w1
herdr pane current --current
herdr pane layout --pane w1:p1
herdr agent list
herdr agent explain <name>

Run a group bare to see its subcommands: herdr agent, herdr pane. Never bare herdr - that launches the TUI.

CLI - create and control

herdr pane split --current --direction right \
  --cwd "$PWD" --no-focus

herdr agent start rev --kind codex --pane w1:p2
herdr agent prompt rev "Review the diff." \
  --wait --timeout 120000
herdr agent wait rev --until blocked --timeout 120000
herdr agent read rev --source recent-unwrapped --lines 120
herdr agent send-keys rev esc
herdr agent get rev

herdr pane run w1:p2 "pytest -q"
herdr pane wait-output w1:p2 --match "passed" \
  --timeout 120000
herdr pane read w1:p2 --source recent-unwrapped

Read sources: visible, recent, recent-unwrapped (best for transcripts), detection. Add --format ansi when colour is evidence.

herdr --default-config      # every option, commented

Rules of thumb

  • Use --no-focus for background work.
  • Target --current, an explicit pane ID, or a unique agent name - never whatever happens to be focused.
  • Do not close panes, tabs or workspaces you did not create.
  • Never herdr server stop from inside a live session unless you mean it.
  • Agent names: [a-z][a-z0-9_-]{0,31}, unique among live agents.
  • Server errors are JSON on stderr, exit 1. Syntax errors exit 2.

Settings worth knowing

ui.agent_panel_sort"spaces" groups by workspace (yours), "priority" floats urgent
ui.mouse_capturetrue - Herdr owns the mouse
ui.copy_on_selecttrue - drag auto-copies
ui.status_indicators"dots" or "symbols"
ui.confirm_closeask before closing a workspace
ui.sidebar_start_collapsedstart with the panel hidden
[[keys.command]]bind your own command to a key - popup, pane, or background

A custom binding, for example lazygit in a popup on Right ⌘ alt+g, is a [[keys.command]] block with type = "popup".
