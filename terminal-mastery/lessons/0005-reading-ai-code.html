Reading code you did not write

If an agent writes the code, review is your job. Here you review a real branch and reject one bad hunk out of many good ones.

Three tools, three zoom levels
gitsignsambient. Gutter marks + who last touched this line. Always on.
diffviewreview. Every changed file, side by side. :DiffviewOpen main...HEAD
neogitdecide. Stage, discard, commit, push. Spaceg
lazygitthe same, outside the editor. Just run lazygit.
