# Format: action-first, no reference material, fast path required

Explicit instruction after reviewing the first build: delete every reference card, delete
the "five things that bite you" and "answer your own question" tables, and stop putting
lookup material in the reading path. He will not read it.

**What stays:** drills he executes, and prose *only* where a concept genuinely needs
explaining (secondmates, the Oil buffer model, the action grammar). Those are the
`explain:` blocks, which always render in both modes.

**What was added:** an Essential / Everything switch per lesson. Essential shows only
steps flagged `key: true` (43-58% of each drill) and matches the advertised time.
Explanations always show. He is time-constrained and this is the accommodation.

**Standing rule:** facts belong inside the step that needs them (`see`, `why`, `warn`),
never in a standalone table he has to consult.
