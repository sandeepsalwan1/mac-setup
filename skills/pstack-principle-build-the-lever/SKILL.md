# Build the Lever

Use an existing tool when it makes repetitive work or verification reliable.
Start occasional operations with the simplest direct path.

- Do the first unit directly to learn the real problem.
- Build a small codemod, script, or reusable recipe only when repetition or a
  concrete blocker makes it useful.
- Prove it on the first unit and make it safe to rerun.
- Prefer one batch operation over delegates repeating the same mechanical edits.
- Keep a reusable tool when later work needs it. Do not build a framework for a
  one-off operation.
