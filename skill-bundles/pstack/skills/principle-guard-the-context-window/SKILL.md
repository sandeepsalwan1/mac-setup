# Guard the context window

Use file lists and scoped searches before reading content. Bound command output and open the relevant ranges. Summarize completed phases with evidence paths and unresolved questions. Preserve the original goal and current decisions across compaction.

Read authoritative files when a decision depends on exact wording. Do not treat a truncated result as a full read. Keep raw transcripts and large logs on disk. This principle does not dispatch work to other agents.
