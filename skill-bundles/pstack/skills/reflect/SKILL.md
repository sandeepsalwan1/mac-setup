# Reflect

Read `../poteto-mode/references/transcripts.md` and locate the active conversation. Review the available conversation directly if its transcript cannot be found, and say so.

Look for recurring corrections, wasted steps, and claims that outran evidence. Separate an explicit user preference from an inferred pattern. Require repeated evidence for an inferred rule. Keep current user decisions authoritative.

Prefer a structural fix when a repeated code mistake can be prevented. Otherwise update one existing rule or skill, tersely. Reuse `stow` when the task is to save broader session knowledge. Preserve unrelated edits and report only the useful change with its evidence.

Do not start Backpass or a review panel. Backpass is periodic maintenance with separate approval, not reflection after every task.
